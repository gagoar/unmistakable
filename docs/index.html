An agent cannot ask what you meant

A tool description, an error message or a system prompt has one reader and no author to call. Every word with two meanings, and every sentence with two parses, is a coin toss. The ASD-STE100 rules were built to remove both, so a maintenance technician could not misread an instruction. An agent is in the same position.

Before

An error may have occurred while processing your request due to a possible mismatch in the expected data format, which could be caused by an outdated client version.

After

Your request may have failed. The cause may be a data format that does not match what the server expects. An outdated client can cause this mismatch. Check your client version.

The rewrite keeps the hedges. “May have failed” stays “may have failed”. Confidence is content, and a rewrite that sounds surer than its author is wrong.

How it works

Three steps. The linter is TypeScript that Node runs as it is. Nothing to install but the plugin, and Node 22.18 or later.

  1. Ask in plain words. “Rewrite this tool description so an agent cannot misread it.” The skill picks strict mode for procedures and error messages, and a lighter mode for READMEs and PR descriptions.
  2. It rewrites without losing a fact. Each flagged sentence is fixed one rule at a time. A condition, a number or a scope qualifier is never dropped to make a sentence shorter.
  3. The linter checks. ste-lint runs on the result and names each remaining problem with the number of the rule behind it.

A linter you can run anywhere

No dependency and no binary: about 60 KB of readable TypeScript. Exit code 1 when hard findings pass the baseline. Good for CI.

$ echo "We spin up the box; it isn't running." | node scripts/ste-lint.ts
<stdin>:1:4 phrasal-verb (STE-9.3): Soft phrasal verb. Use the single plain verb ... [spin up]
<stdin>:1:19 semicolon (STE-8.1): STE bans the semicolon (Rule 8.1). Split into separate sentences. [;]
<stdin>:1:24 contraction (STE-4.2): Contraction. Write the full words ... [isn't]

What it checks

Structure, not meaning. It has no part-of-speech tagger, and it never flags a hedge.

Semicolons, phrasal verbs, nominalizations, passive voice, compound tenses, one term per action, sentence length, paragraph length, contractions, -ing forms, multi-word nouns, WARNING and CAUTION blocks, dropped articles, British spellings, marketing adjectives and dangling conjunctions in lists. Each finding carries its rule number (STE-6.6). A check that is not an STE rule has the prefix X-.
